Help

Close the game before changing saves. Save current run makes a snapshot; Save & load out also frees the multiplayer slot. Load in restores a saved run. Save again or use Update from game after playing.

Load in/out updates the selected profile’s local and Steam Cloud multiplayer files. Keep Steam open and signed into the same account. Both copies are backed up before swapping; solo runs and profile progress are preserved. Multiplayer saves require the original party; transfer to a different host may not work.

Removed runs are kept in the storage folder’s trash subfolder. Custom folders outside the game’s standard Steam profile layout are managed locally.
